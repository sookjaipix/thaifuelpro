# ⛽ THAI FUEL TRACKER PRO (เว็บแอปติดตามและคำนวณราคาน้ำมัน)

เว็บแอปพลิเคชันระดับมืออาชีพสำหรับติดตามราคาน้ำมันเรียลไทม์ในประเทศไทย พร้อมระบบคำนวณอัตโนมัติ และระบบสะสมปริมาณน้ำมัน (ลิตร) และยอดเงิน (บาท) ที่จ่ายไปแยกจากกันอย่างชัดเจน ใช้งานได้สมบูรณ์แบบทั้งบนคอมพิวเตอร์และมือถือ (Responsive & PWA Ready)

---

## 🌟 ฟังก์ชันหลักของระบบ

### 1. ⛽ ราคาน้ำมันเรียลไทม์ทุกปั๊มและทุกชนิดน้ำมันในไทย
- **ครอบคลุม 6 ผู้ค้าน้ำมันหลัก**: PTT Station (ปตท.), บางจาก (BCP), เชลล์ (Shell), พีที (PT Station), คาลเท็กซ์ (Caltex), และซัสโก้ (Susco)
- **ครอบคลุมทุกชนิดน้ำมัน**:
  - กลุ่มแก๊สโซฮอล์: แก๊สโซฮอล์ 95, แก๊สโซฮอล์ 91, แก๊สโซฮอล์ E20, แก๊สโซฮอล์ E85
  - กลุ่มดีเซล (แยกชัดเจนตามมาตรฐาน):
    - **น้ำมันดีเซล B7**: มาตรฐานสำหรับรถยนต์ดีเซลทั่วไป
    - **น้ำมันดีเซล B20**: สำหรับรถบรรทุก รถเชิงพาณิชย์ ช่วยประหยัดต้นทุน
    - **น้ำมันซุปเปอร์ดีเซล (พรีเมียม B7)**: Super Power Diesel B7, V-Power Diesel, Hi-Premium Diesel S B7 ค่าซีเทนสูง เพิ่มแรงบิด
    - **น้ำมันดีเซลธรรมดา**: ดีเซลมาตรฐานทั่วไป
  - กลุ่มเกรดพรีเมียม: พรีเมียม แก๊สโซฮอล์ 95/97, ซุปเปอร์ดีเซล (พรีเมียม B7)
  - กลุ่มเบนซินบริสุทธิ์: เบนซิน 95 (เพียว)
  - กลุ่มก๊าซธรรมชาติ: ก๊าซ NGV / CNG
- **โหมดเปรียบเทียบทุกปั๊ม (Comparison Matrix)**: เปรียบเทียบราคาข้ามปั๊มแบบเคียงข้างกัน พร้อมแสดงราคาก่อนหน้าและสัดส่วนส่วนต่างว่าปรับขึ้นหรือลดลงกี่บาท ไฮไลท์ราคาถูกที่สุดให้อัตโนมัติ
- **โหมดดูเฉพาะปั๊ม (Cards View)**: แสดงการ์ดข้อมูลน้ำมันแต่ละชนิด พร้อมแสดงราคาก่อนหน้า (Previous Price) และส่วนต่างว่าห่างจากราคาปัจจุบันกี่บาท (+/- บาท และ %)
- **ระบบเชื่อมต่อ API เรียลไทม์**: ดึงราคาล่าสุดอัตโนมัติ พร้อมปุ่มรีเฟรช และมีระบบแคชออฟไลน์รองรับเมื่อไม่มีสัญญาณอินเทอร์เน็ต
- **ปรับแต่งราคาเฉพาะพื้นที่ได้**: รองรับการแก้ไขราคาเองกรณีเติมในต่างจังหวัดที่มีค่าขนส่งเพิ่ม

### 2. 🧮 ระบบเครื่องคำนวณน้ำมันอัจฉริยะ (Smart Real-Time Calculator)
- **โหมดใส่จำนวนเงิน ➔ คิดจำนวนลิตร**: พิมพ์จำนวนเงิน (เช่น 1,000 บาท) ระบบจะนำราคาน้ำมันเรียลไทม์มาหารและแสดงผลลัพธ์เป็นจำนวนลิตรทันที ทศนิยม 3 ตำแหน่ง พร้อมแสดงสูตรคำนวณ
- **โหมดใส่จำนวนลิตร ➔ คิดจำนวนเงิน**: ระบุจำนวนลิตรที่ต้องการเติม (เช่น 25 ลิตร) ระบบคำนวณยอดเงินที่ต้องจ่ายให้อัตโนมัติ
- **โหมดคำนวณเติมเต็มถัง (Full Tank Estimator)**: ระบุขนาดถังน้ำมันรถของคุณ และระดับเกจ์ที่เหลือ ระบบคำนวณลิตรที่ต้องเติมเพิ่มและงบประมาณที่ต้องจ่ายทันที
- **ปุ่ม Preset ด่วน**: กดเพิ่มเงิน (+300฿, +500฿, +800฿, +1,000฿, +1,200฿, +1,500฿, +2,000฿) หรือเพิ่มลิตร (+10L, +20L, +30L, +40L, +50L) เพื่อความสะดวกรวดเร็ว
- **บันทึกลงระบบสะสมทันทีในคลิกเดียว**: สามารถระบุทะเบียนรถ, เลขไมล์กิโลเมตร, วันที่เวลา และหมายเหตุ เพื่อบันทึกเข้าสู่ประวัติ

### 3. 📅 เมนูบันทึกและสรุปแยกรายเดือน (Monthly Accumulator & Breakdown)
- **แยกยอดเงินและลิตรในแต่ละเดือนอย่างอิสระ**: แสดงยอดเงินรวมค่าน้ำมัน (บาท) และปริมาณการใช้น้ำมัน (ลิตร) ของแต่ละเดือนอย่างเด่นชัด
- **ปุ่มเลือกเดือน (Month Selector Chips)**: สลับดูรายงานของแต่ละเดือนได้สะดวกรวดเร็ว
- **การเปรียบเทียบเทียบเดือนก่อนหน้า (Month-over-Month)**: มี Badge วิเคราะห์ว่าเดือนนี้จ่ายเพิ่มขึ้นหรือประหยัดลงกี่บาท (+/- %) และใช้น้ำมันมากขึ้นหรือลดลงกี่ลิตร (+/- %)
- **สัดส่วนชนิดน้ำมันและปั๊มในแต่ละเดือน**: วิเคราะห์ว่าในเดือนนั้นใช้น้ำมันชนิดใดมากที่สุด (เช่น ดีเซล B7, ดีเซล B20, ซุปเปอร์ดีเซล)
- **ตารางเปรียบเทียบย้อนหลังทุกเดือน**: รวมสถิติทุกเดือนในตารางเดียว (ปรับเป็นการ์ดขนาดกะทัดรัดเมื่อเปิดบนมือถือ)

### 4. 📋 ระบบสะสมจำนวนลิตรและยอดเงินที่จ่ายไป (ภาพรวมสะสมทั้งหมด)
- **4 การ์ดสรุป KPI เด่นชัดบนแดชบอร์ด**:
  1. 💳 **ยอดเงินค่าน้ำมันสะสม (Total Spent)**: แสดงยอดเงินรวมเป็นบาท (สีเขียวมรกต) พร้อมค่าเฉลี่ยต่อครั้ง
  2. 🛢️ **ปริมาณน้ำมันสะสม (Total Liters)**: แสดงจำนวนลิตรรวม (สีฟ้านีออน) พร้อมค่าเฉลี่ยลิตรต่อครั้ง
  3. ⚖️ **ราคาเฉลี่ยต่อน้ำมัน 1 ลิตร**: คำนวณจริงจาก `ยอดเงินรวมสะสม ÷ จำนวนลิตรรวมสะสม`
  4. 🚘 **สถิติ & ประสิทธิภาพ**: อัตราสิ้นเปลืองเฉลี่ย (กิโลเมตร/ลิตร) และต้นทุนการเดินทาง (บาท/กิโลเมตร) คำนวณจากเลขไมล์ที่บันทึก
- **รายงานสรุปแยกหมวดหมู่**:
  - สรุปสะสมแยกตามชนิดน้ำมัน (ลิตรสะสม, ยอดเงิน, สัดส่วน %)
  - สรุปสะสมแยกตามปั๊มน้ำมันที่เข้าใช้บริการ (ลิตรสะสม, ยอดเงิน, สัดส่วน %)
- **ตารางประวัติการเติมละเอียด**:
  - รองรับการกรองตามช่วงเวลา (ทั้งหมด, เดือนนี้, เดือนก่อน, ปีนี้)
  - กรองตามปั๊ม และกรองตามชนิดน้ำมัน
  - รองรับการลบหรือแก้ไขรายการ
- **การจัดการข้อมูล**:
  - ส่งออกข้อมูลเป็นไฟล์ Excel / CSV (รองรับภาษาไทย UTF-8 BOM เปิดใน Excel ภาษาไทยไม่เพี้ยน)
  - สำรองข้อมูล (Backup JSON) และ กู้คืนข้อมูล (Restore JSON)
  - ปุ่มโหลดข้อมูลจำลองเพื่อทดลองใช้งาน (Sample Data)

### 4. 📊 กราฟและสถิติวิเคราะห์ (Analytics)
- กราฟแท่งและเส้นเปรียบเทียบแนวโน้มค่าใช้จ่ายรายเดือนและปริมาณลิตร (Dual-Axis Chart)
- กราฟโดนัทแสดงสัดส่วนชนิดน้ำมันที่เติมบ่อยที่สุด (Fuel Share Doughnut)

### 5. 🎨 ดีไซน์และหน้าตาเว็บไซต์ (Executive White & Gray Theme)
- คุมโทนสีขาว-เทา (White & Slate Gray) สะอาด สบายตา ทันสมัย เรียบหรูสไตล์ Minimal Executive Dashboard
- แสดงผลชัดเจน คมชัด อ่านง่ายทั้งในที่ร่มและกลางแจ้ง
- รองรับ Responsive เต็มรูปแบบ:
  - **บนคอมพิวเตอร์**: แสดงแท็บแนวนอนด้านบน, ตารางสถิติแบบเต็ม และการ์ด 4 คอลัมน์
  - **บนมือถือ**: มี Bottom Navigation Bar สำหรับใช้นิ้วโป้งสลับแท็บได้สะดวกรวดเร็ว, ตารางจะปรับเป็นการ์ดขนาดกะทัดรัดอ่านง่าย
- รองรับการติดตั้งแบบ PWA (Add to Home Screen) เป็นไอคอนแอปบนหน้าจอมือถือ

## 🚀 วิธีเปิดใช้งาน

### วิธีที่ 1: เปิดผ่านเบราว์เซอร์โดยตรง (ไม่ต้องติดตั้งโปรแกรมเพิ่ม)
- ดับเบิลคลิกเปิดไฟล์ `index.html` ผ่าน Google Chrome, Safari, Microsoft Edge หรือเบราว์เซอร์ใดก็ได้ ใช้งานได้ทันที

### วิธีที่ 2: รันผ่านเซิร์ฟเวอร์ Localhost (สำหรับการใช้งานทั้งในคอมพิวเตอร์และมือถือผ่าน Wi-Fi)
1. เปิด Terminal ในโฟลเดอร์นี้
2. รันคำสั่ง:
   ```bash
   python3 server.py
   ```
3. เปิดเบราว์เซอร์ไปที่:
   - **บนคอมพิวเตอร์**: `http://localhost:8080`
   - **บนมือถือ (ต่อ Wi-Fi วงเดียวกัน)**: `http://<IP_เครื่องคอมของคุณ>:8080`
