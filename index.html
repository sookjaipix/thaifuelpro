🔗 เปิด Google Sheets
ลิงก์ Web App ที่ได้จากการกด "ทำให้ใช้งานได้ (Deploy) > การทดลองใช้งานเว็บแอป (Web App)" ใน Google Sheets
📖 วิธีเชื่อมต่อ Google Sheets ใน 3 ขั้นตอนง่ายๆ
▼
  1. เปิด Google Sheets แผ่นงานใหม่บน Google Drive ของคุณ
  2. ไปที่เมนูด้านบน ส่วนขยาย (Extensions) > Apps Script
  3. ลบโค้ดเดิมออกทั้งหมด แล้วคลิกปุ่ม "คัดลอกโค้ดสำเร็จรูป" ด้านล่างนี้ไปวาง
  4. คลิกปุ่ม บันทึก (Save 💾) แล้วกด ทำให้ใช้งานได้ (Deploy) > การทดลองใช้งานเว็บแอป (New deployment: Web App)
  5. ในช่อง ใครมีสิทธิ์เข้าถึง (Who has access) เลือก ทุกคน (Anyone) แล้วกด Deploy
  6. คัดลอก Web App URL นำมาวางในช่อง Webhook ด้านบน แล้วกด บันทึกการตั้งค่า
